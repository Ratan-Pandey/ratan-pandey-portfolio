# Ratan Pandey Ai Atlas

Build a premium, visually exceptional, fully responsive personal portfolio website for **Ratan Pandey**, an Independent AI/ML Developer and Freelance Builder from India.

## PRIMARY OBJECTIVE

This website is being created to establish Ratan's professional identity as an independent technology builder for professional networking, startup collaborations, and Google's Builder Pop-up event for working professionals.

The website must NOT look like a student resume or a generic developer portfolio.

It should feel like the online presence of an ambitious independent AI developer who builds real-world technology products, experiments with emerging technologies, and has a long-term vision for applying AI to agriculture and sustainability.

## PERSONAL BRANDING

Name: Ratan Pandey

Professional title: Independent AI & Machine Learning Developer | Freelance Builder

Tagline: Building intelligent technology for real-world impact.

Professional positioning:
Ratan develops practical AI-powered applications across machine learning, NLP, geospatial intelligence and software engineering. He is currently independently developing Urban Green Cover Intelligence and exploring its potential expansion into a larger AI-for-agriculture initiative.

## DESIGN DIRECTION

Create an exceptional dark-themed editorial portfolio.

Visual inspiration:

- Premium independent developer portfolios.
- Minimalist startup founder websites.
- Modern AI technology studios.
- High-end creative developer portfolios.

Design system:

- Background: near-black charcoal (#0B0E0C).
- Primary accent: electric lime / muted emerald.
- Secondary colors: forest green, muted grey and off-white.
- Typography: Manrope, Inter or similarly sophisticated fonts.
- Generous whitespace.
- Large editorial headings.
- Thin borders and subtle gradients.
- Beautifully designed project cards.
- Smooth scrolling and sophisticated micro-interactions.

Avoid excessive gradients, generic AI illustrations, unnecessary glassmorphism and clutter.
